FINAL YEAR PROJECT

Real-Time Active Noise Cancellation on Embedded Linux

The Problem

Standard Windows/MATLAB-based signal processing introduced 50–100 ms of latency, making real-time active noise cancellation physically impossible — a delay of that magnitude would require a 34-metre waveguide to compensate.

The Solution

Pivoted to a real-time Embedded Linux architecture (Raspberry Pi) running Python-based FxLMS adaptive filtering algorithms. Bypassed OS-level audio stacks by interfacing directly via Linux I2S, achieving deterministic low-latency processing.

Technical Achievement

Reduced end-to-end system latency to 4.477 ms, achieving −10.1 dB attenuation at the target frequency.
